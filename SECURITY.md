# Security policy

The Verified Bundle mark proves only that a repository contains a `dsh.bundle.patch` declaration and the referenced patch file at scan time. It does not prove that the code is safe, maintained, compatible, or free of malicious dependencies.

Report vulnerabilities in this repository through GitHub private vulnerability reporting when available. For a third-party plugin vulnerability, contact that plugin's maintainer first. Open a public issue here only when users need an ecosystem warning and disclosure is already safe.

Never include API keys, private repository data, or full local profile contents in an issue or scan fixture.
