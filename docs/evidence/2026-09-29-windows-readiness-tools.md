# Fixed Windows readiness tool replay on DSH 0.2 RC1

The previous Windows readiness evidence proved isolated `github:` installation and headless configuration composition, but not tool execution. On 2026-09-29, the latter failed: the installed `index.js` imported optional `@deepseek-ai/dsh-tools`, which the isolated installer did not provide. This was a real install-versus-load gap, not a host-readiness failure.

The plugin fix at [`46cc6b8`](https://github.com/dongsheng123132/dsh-windows-readiness-proof/commit/46cc6b8dbaa0f970ffa326615cb1e52683516929) removes that runtime import and declares self-contained tool definitions. The proof below pins official DSH `dsh-v0.2.0-rc.1` to `4878cdabd87d4041bdaff61d04c966883b9fd07a`, Node 24.19.0, pnpm 11.7.0 and the plugin commit. Local Windows validation used fresh stock, local-install and GitHub-install DSH_HOME directories. The GitHub-installed bytes were compared with the fixed plugin commit before calling the official Context/SystemPrompt/ToolRuntime services.

`windows-readiness-runtime-smoke.ts` enumerates both DSH tools, runs manifest inspection, verifies a sanitized 26-control fixture and independently reads back the report SHA-256 (`98fd800ccf76f57cea01edbf4e5e21f537a4da368bec6a14f03bca6a44780390`), then asserts that traversal is rejected. It never collects live Windows host state. The same deterministic fixture runs on Ubuntu to test portable evaluation, not to claim Ubuntu is a managed Windows host. The plugin's local suite has 11 passing unit tests, check, MCP smoke, plugin smoke and the Codex plugin validator.

The workflow `windows-readiness-tool-smoke.yml` replays stock CLI, fixed GitHub installation/composition and real service-level business calls on clean Ubuntu and Windows runners. Its scope is one fixed plugin and service-level ToolRuntime. It does **not** establish full headless/Web profile Loader startup, model-mediated tool use, or compatibility of the whole Lab catalog. The 0.2 RC1 runtime remains an observed target, not the Lab's default baseline.
