# DSH 0.2 RC2 Web/headless business parity

This is a runtime evidence slice for two previously verified Labs, not a new plugin or a general compatibility certification. It extends the [Web Loader](2026-10-01-v020rc2-profile-loader.md) and [headless Loader](2026-10-01-v020rc2-headless-loader.md) boot evidence from registration to direct ToolRuntime business calls through each complete profile.

The [Ubuntu/Windows workflow](../../.github/workflows/profile-business-parity.yml) pins official DSH at `639ed015397290b3745d163aafe02ffee4aa3f84`, support-lifecycle-proof at `df33364fee39fbb55b53b8c290df6b28d0f072c6`, and windows-readiness-proof at `46cc6b8dbaa0f970ffa326615cb1e52683516929`. It performs the official frozen install and `build:lib`, then uses distinct fresh `DSH_HOME` values for Web and headless stock compose, fixed-commit `github:` installs, full `runProfile` Loader boot, and direct ToolRuntime calls. Each probe creates a separate temporary workspace for sanitized fixtures and report artifacts.

Per profile, six assertions cover support inspect, closed proof with SHA-256 read-back, missing-retirement non-closure, Windows readiness inspect, verified 26-control report with SHA-256 read-back, and workspace-traversal rejection. CI compares the two report hashes across the profiles on each OS. The probe suppresses runtime output, including the Web bearer URL, removes inherited credential-shaped environment, has timeouts, and publishes only tool counts, case names, and report hashes. It does not run a model turn or assert an agent answer. Registered tool counts differ between profiles because stock tools differ; report hashes and verdict semantics are the comparison target.

Local Windows controls used two new isolated profile homes. Web and headless both passed all six cases with support report SHA-256 `44ad888bce2f282554b8f6afa5971f4c0b1ff9e51bbb6a1918a1122e9f0fb6d6` and Windows report SHA-256 `98fd800ccf76f57cea01edbf4e5e21f537a4da368bec6a14f03bca6a44780390`. The CI run is the clean-runner evidence; this does not imply all 40 Labs or every DSH release is compatible.
