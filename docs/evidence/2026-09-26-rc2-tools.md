## Reproduce

Use an isolated checkout of the DSH revision above, run `pnpm install --frozen-lockfile`, and use a new DSH_HOME. From that DSH checkout:

```powershell
$env:DSH_HOME = '<new-isolated-dsh-home>'
pnpm run dsh -- plugin --profile headless add 'github:dongsheng123132/dsh-support-lifecycle-proof#df33364fee39fbb55b53b8c290df6b28d0f072c6'
pnpm run dsh -- --profile headless --dump-config
node --import tsx/esm '<awesome-checkout>/docs/evidence/rc2-support-lifecycle-smoke.ts' '<new-isolated-dsh-home>/profiles/headless/node_modules/dsh-support-lifecycle-proof' '<support-lifecycle-proof-git-checkout>'
```

The last checkout must contain the plugin commit above, so the script can read its fixture with `git show`. The script verifies the DSH HEAD, tracked source cleanliness, and installed plugin source bytes before running the three business cases. It leaves the newly created temporary test workspace for inspection; it does not read a user's profile or credentials.

This proves Windows service-level registration and business calls for one immutable plugin/runtime tuple. Full profile Loader activation, Linux behavior, model-mediated calls, and all other plugins remain unverified here. The runtime matrix default and Lab compatibility claims are unchanged.
